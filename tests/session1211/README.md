The object scene is an original synthetic fixture drawn for these tests: a red
handled cup and a blue bottle on a table. The second original fixture has a touching apple/vase pair and a detached yellow container. It is distributed under the repository
MIT license. Click prompts must select different complete objects rather than
the entire foreground. Tests run the pinned SlimSAM ONNX graphs locally.

The other cases exercise format-9 save/reopen and rejection of invalid metadata,
immutable decoded assets, save failure recovery, captured history revisions,
guide geometry, feather coverage, trim, and actual editor controls. Generated
captures and projects belong under the CMake build directory.
